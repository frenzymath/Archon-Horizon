# Formalization

Complete the objective using the shared workspace. Choose useful routes, helpers
and decomposition; a graph node need not correspond to a separate session. Keep
work published through safe worktrees and publication rather than sharing one
mutable Git index. There is no routine proof PR gate on workspace work.

Use roadmap PRs for graph additions, edits, retirement, objective corrections and
milestone amendments. Keep accepted contracts stable unless a reviewed change is
justified. Use new linked identities where provenance matters, and repair dependents when
modifying or deleting nodes. Git retains accepted source history.
A theorem using an admitted prerequisite remains conditional. Record the exact
source, declarations and trusted dependency/axiom evidence for completion claims.

Narrow a difficult result into useful children, investigate a changed route, or
ask for a concrete decision. Diagnose failed sessions before repeating them and
preserve their owners. A bounded session can finish after faithful delegation with
a durable integration owner; its mission stays open until accepted. Maintainers
record phase acceptance when the requested mathematical outcomes have evidence.
