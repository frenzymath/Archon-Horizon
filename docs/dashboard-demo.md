# Dashboard demo

[Open the published read-only dashboard](https://frenzymath.github.io/Archon-Horizon/demo/).
For a local documentation build, <a href="../demo/">open the local demo</a>.

The demo uses the actual React dashboard with a small invented project. Explore
the project overview, objective checkboxes, node directory, a node's DAG,
references, and the Activity run/session views. The simulated administrator also
sees sample execution hosts, provider harnesses, reviewer configuration, skills,
prompt templates and the subagent library. Data is fixed at a synthetic
timestamp so regenerated builds can be compared.

There is no server, account login, provider execution, database, or external
integration. The simulated account has administrator visibility but no write
permission or real credential. Forge and Zulip tabs embed local, clearly labelled
synthetic previews of a repository, proposals, channels and discussion topics;
they are not running Forgejo or Zulip installations. The demo transport rejects
mutations and unknown reads; a restrictive browser policy blocks network
connections and external frames; only same-origin preview frames are allowed.
Refreshing or sharing a query URL below
the demo path preserves the selected view.

The bibliography, model name, token counts and proof labels are examples. They
are not records of real sessions or a verified mathematical library. This demo
illustrates navigation and presentation, not orchestration or sandbox behavior.

The fixture is generated by `scripts/generate_dashboard_fixture.py` from literal
synthetic values and selected public bundled instruction files. It deliberately
cannot import an installation snapshot. See
[documentation development](documentation-site.md) for regeneration and preview.
